# 🏥 Hospital Patient Analytics

A portfolio project documenting my journey toward becoming a Health Informatics professional through SQL, Git, Python, and healthcare data analytics.

---

## 📌 Project Overview

This project uses a healthcare dataset to practice SQL and data analytics by solving real-world hospital reporting and business problems.

The goal is not only to learn SQL syntax but to develop analytical thinking using healthcare data.

- Learn Python for healthcare analytics
- Build interactive healthcare dashboards
- Develop a professional Health Informatics portfolio
